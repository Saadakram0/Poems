# Saad Akram — poetry 
A that opens with a short animated intro, moves into a brief about-me screen, then lets visitors page through a collection of original Urdu 

## Features

- Three-screen flow: Intro → About → Poetry, with fade/rise transitions
- Urdu poems rendered in Noto Nastaliq Urdu, right-to-left, with prev/next navigation and a date stamp per poem
- Floating heart particle background animation
- Dark theme with a red/gold accent palette
- Fully responsive, safe-area aware (looks right on notched phones)
- Zero dependencies beyond Google Fonts — pure HTML/CSS/vanilla JS, no build step
